# Tax Return Tracker

Tax Return Tracker 是办公室内网使用的报税资料工作台。员工通过浏览器登录，按客户和税年管理资料、跟进缺件，并对照原件核对金额。应用、识别任务和客户资料集中保存在办公室服务器。

## 从文件夹路径到核对

```mermaid
flowchart LR
    A["输入客户资料文件夹路径"] --> B{"能确认客户姓名？"}
    B -->|能| D["建立年度工作区"]
    B -->|不能| C["保留路径，补填姓名"]
    C --> D
    D --> E["后台导入 PDF 和图片"]
    E --> F["识别表格和金额"]
    F --> G["资料清单：查看表格和登记缺件"]
    G --> H["对照原件，核对金额和申报位置"]
```

- **客户总表**支持按税年、工作阶段和关键词筛选。年度档案可记录负责人、截止日期、备注、收费和操作历史。
- **资料清单**显示导入进度、已识别表格和缺件待办。会计可以将应交资料关联到原件。
- **表格核对**可按 W-2、1099-DIV、1099-INT、1099-B 等表格查看原件页和已提取金额。已覆盖的项目会提供联邦税表、行号或附表参考。会计可以确认归属、修正金额并记录审核结果。
- **文件与路径**可分别登记原始资料、税表和 ProSeries 客户文件的位置。

系统对支持的表格提取金额，并保留原件供人工复核。金额可能漏读或误读，申报位置是核对参考。当前版本不计算税额、不自动录入 ProSeries，也不执行电子申报。GPT API 和批量建档尚未接入。

## 启动和部署

在 Windows 工作站双击 `run_windows.bat`。首次启动按提示设置管理员密码。默认资料目录为 `%LOCALAPPDATA%\TaxPrepLocal`。建议使用合成演示资料或独立的测试资料目录验证流程。详见[工作站安装说明](INSTALLATION.md)和[本机使用指南](LOCAL_GUIDE.md)。

办公室服务器的 HTTPS、开机启动、账号、备份和恢复配置见[服务器部署指南](SERVER_GUIDE.md)。管理员管理账号和备份，编辑员工负责导入和核对，只读员工可以查看。当前启用的员工账号共享客户列表，负责人用于分工。

代码位于 `taxtracker/`，按用途分为客户与资料管理（`clients`）、表格与提取（`documents`）、审核与底稿（`verification`）、账号和运维工具（`operations`）。根目录保留 Windows 启动入口。自动测试放在 `tests/`，测试报告放在 `docs/testing/`。

Windows 开发环境可运行以下命令执行自动测试。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
