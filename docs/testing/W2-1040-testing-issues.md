# W-2 → 1040 流程测试问题与修复记录

测试日期：2026-11-09。

输入目录：`D:\TaxTrackerTesting\input\sample-1040`。文件：`testing.pdf`，一页 2025 年 W-2，页内包含四联副本。本次测试和修复针对 `server-work` 服务器版代码，未修改旧版 `TaxPrep-Local-v0.6`。

## 结论

PDF 文字读取成功，使用 `pdf_text`，没有调用 OCR。问题发生在读取后的字段提取阶段：W-2 版面规则只覆盖六项联邦字段，未覆盖 Box 16 和 Box 17。此外，本样本的州税金额印在字段标签上方，不能沿用只向标签下方找金额的方式。

已修复并使用原始 PDF 在新的隔离工作区复测。八项字段自动提取全部正确，没有人工补录。导入、重复上传拦截、审核门槛、页面确认和底稿导出通过。

## 修复方法

- 修改 `server-work/extract.py`，使用 Box 15、16、17 标签的相对位置定位州税区域。
- 支持金额位于标签上方或下方，并保存金额的页面坐标证据。
- 限制在选中的同一联 W-2 内取值，避免从旁边或下一联取值。
- 限制到地方税栏之前；同一州税栏有多行金额时保持空白，交由人工确认，不自动合并。
- 本次未扩展多州明细数据模型，也未增加税额计算或 1040 生成。
