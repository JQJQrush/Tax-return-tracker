# CRM 框架首轮实施与验证

日期：2026-11-10。需求基准：根目录 `CRM_FRAMEWORK.md`。

## 已实现

- `/` 为客户总表，支持搜索、税年和工作阶段筛选。
- 按年度每位客户一行，全部年度按客户展开历史。
- 资料摘要可展开为 bullet points，点击进入年度资料清单。
- 长期客户档案与年度工作区分离，支持为已有客户新增年度，阻止同客户重复年度。
- 年度概况、工作/申报状态、三类日期、服务费应收/已收及余额。
- 原始资料文件夹、税表文件夹、ProSeries 客户文件路径分别保存。
- 支持一个资料项目关联多个文件/页面，支持一个文件关联多个项目；验证项目、文件、页码属于同一年度。
- 上传 PDF 可打开原件或进入该文件的核对页面，外部图片/文件可登记路径。
- `/workspace?client_id=...` 保留既有 PDF 读取、核对、反馈、交接和导出能力，并提供返回 CRM 入口。
- CRM 保存使用客户和年度两组修订号，阻止旧页面覆盖其他员工修改；只读权限沿用服务器认证。
- CRM 变更历史和关联随数据库备份/恢复保存。
- 网络连接失败改为中文提示。

## 数据迁移

旧 `clients` ID 继续作为年度工作区 ID。新增 `contacts`、`crm_years`、`crm_links`、`crm_history`。迁移重复运行不会重复建档；不根据相同名称自动合并旧客户。旧客户、文件、页面和审核记录保留。用户已有服务于 8765 端口重启加载新版，登录页返回 HTTP 200。

升级前确认无正在识别的文件，并将现有完整资料备份保存到 `.sample-1040-qa/pre-crm-2026-11-10.zip`。该文件包含客户资料，不应进入分发包。

## 验证

- 完整自动测试：61 项通过。
- 新增 CRM 测试覆盖重复迁移、同名隔离、年度唯一性、跨年度联系人更新、并发冲突、跨客户文件关联拒绝、页码校验及备份恢复。
- 认证 API 测试覆盖编辑写入、409 冲突、viewer 写入拒绝，以及首页和年度核对路由。
- 新旧页面脚本均通过 `node --check`。
- 独立合成数据浏览器检查：资料 bullet 展开正确、三类路径可保存，进入核对工作台选择的是指定客户年度。

## 明确边界

- 外部路径只登记，不自动复制、备份外部文件、打开本机文件夹或启动 ProSeries。
- PDF 自动读取沿用现有引擎；图片自动 OCR 尚未接入。
- 服务费为汇总和修改历史，尚非逐笔收款账本。
- 申报状态是员工人工跟踪，不调用 ProSeries 或税局接口。
- 旧客户跨年归并、文件关联修改/删除、更正版本专用操作等仍需后续细化。
