# 通过文件夹创建客户

2026-11-10：已将姓名与资料文件夹路径至少填一项接入新建客户。只填路径时从PDF/图片内容的纳税人、员工或收件人姓名标签读取姓名，记录证据并写入数据库，自动登记文件路径；不使用文件夹名猜测，不取雇主或配偶标签。

姓名无法确认、文件读取失败或多人姓名冲突时提示人工填写，不创建不可靠客户。明确填写姓名时可直接建档；填写路径需要服务器可访问。扫描件调用本机Tesseract，不调用云端服务。

为避免长时间阻塞，姓名读取限制顶层40份以内、每份前两页，总时长受限；现阶段英文OCR及数字PDF姓名标签为主要支持范围，扫描中文需更多语言模型支持。文件路径关联不等于文件已复制归档，金额提取仍由年度工作台导入处理。

相同年度、相同资料目录且姓名相符时打开现有客户，不重复建档。不存在或无权限的路径会提示修正；失败时保留表单内容。
