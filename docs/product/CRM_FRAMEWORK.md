# TaxPrep CRM 框架与实施约定

确认日期：2026-11-10。用户确认 ProSeries 路径指客户报税数据文件。

## 客户与年度

客户档案长期存在，联系方式属于客户；每个客户有独立年度工作区。选择税年时每个客户一行；全部年度视图按客户展开历史年度。旧客户工作区保留原 ID、资料及审核记录，不根据姓名自动合并客户。

### 新建客户输入规则（2026-11-10 已实现）

客户姓名与资料文件夹路径至少提供一项，两项都可填写。只填写路径时，读取该文件夹资料中的 taxpayer 姓名，建立客户档案并写入数据库；文件夹名仅作辅助依据，不能当成已验证姓名。识别失败、出现多个可能客户、或输入姓名与资料姓名不一致时，提示用户确认，不猜测或按付款方名称建客户。夫妻联合申报需要区分纳税人与配偶。已接入创建表单：姓名可空，路径至少一项；从内容读取姓名并保存来源证据，关联文件路径。当前读取顶层文件前两页，姓名识别失败或冲突时不建档，提示人工确认。

## 首页

客户总表展示客户信息、税年、工作阶段、负责人、截止日期、资料情况、服务费付款。资料情况使用展开/收起控件：摘要显示待收和已收数量，展开后用 bullet points 展示资料项目，并进入对应客户资料。提供搜索、税年和阶段筛选。

## 客户年度工作区

包括概况、应交资料、文件与路径、表格核对、收费记录和操作历史。原始资料文件夹、税表文件夹、ProSeries 客户文件路径分别保存。路径保存不意味着文件已被复制、已备份或已录入 ProSeries。

## 文件关联与读取

资料项目、实际文件、文件页、提取记录分开管理。一个项目可关联多个文件/页面，一个文件可服务多个项目。W-2 记录可以追溯到原文件和页码；文件也可查到提取记录。重复副本不重复计入，更正版本保留说明。

本地 PDF 读取和人工核对沿用已有引擎；识别结果默认候选。PDF、图片、外部文件路径需要明确区分。首轮继续支持 PDF 自动读取；图片和外部文件可以登记路径，自动图片 OCR 后续实现，界面明确边界。

## 状态与日期

工作阶段、资料收集状态、申报状态、服务费收费状态分开。日期分别记录内部目标、申报截止、付款到期。服务费与客户税款分开；录入申报状态是跟踪记录，不代表平台提交或查询了申报。

## 工作流程

客户总表 → 客户年度工作区 → 收集和关联资料 → 读取与核对 → 复核/签字/申报跟踪 → 交付归档。

## 实施顺序

1. 客户长期档案与年度关联、兼容迁移。
2. CRM 首页与客户年度详情、年度创建、状态/日期/服务费/路径保存。
3. 资料、文件、页码关联和原件/核对入口。
4. 权限、并发冲突、历史、备份恢复与流程回归验证。

现有核对工作台保留为年度内的功能。首轮服务费为应收/已收汇总与变更历史；逐笔收款、税款管理、自动截止日推算及 ProSeries 自动连接后续另行设计。
