# TaxPrep Local v0.6 软件介绍

TaxPrep Local 是一款面向美国个人报税业务的本机资料整理与核对工具。它把客户提交的 PDF、应交资料清单、金额核对记录和录入底稿放在同一个客户工作区，帮助团队在正式录入税表前查找原件、跟进缺件、核对金额和交接待办。软件在 Windows 上启动，通过中文浏览器界面操作，客户资料在本机处理。

## 适用对象

- **资料收集人员和报税助理**可以按客户和税务年度归档 PDF，登记应交资料，跟进缺件并生成催收草稿。
- **税表录入人员**可以对照 PDF 原页核对表格、归属和金额，再用底稿辅助在 ProSeries 等报税软件中手工录入。
- **复核人员**可以查看待审核记录、金额冲突和修改历史，定位原页并把未完成事项交给下一位经办人。

## 主要功能

| 功能 | 实际用途 |
| --- | --- |
| 客户工作区与资料追踪 | 按客户代号和税务年度管理资料。记录待收、已收和不适用项目，可将已收项目关联至上传的原件。催收草稿由经办人自行发送。 |
| PDF 导入与本机识别 | 区分客户原始资料与已完成税表，预览 PDF 原页并读取文字。安装 Tesseract 后可对扫描件做英文 OCR。同一客户内可拦截内容完全相同的 PDF。 |
| 表格识别与人工核对 | 识别常见 W-2、SSA-1099、1099-INT、1099-DIV 和 1099-B 类型，并在受支持的版式中提取部分金额候选。经办人可对照原页修正、补录或排除页面与记录。 |
| 金额检查与复核交接 | 提示部分金额算式冲突、疑似重复和证券汇总与明细同时计入的问题。可将已核对的部分收入金额与已完成的 Form 1040 对照，并汇总待收、待识别和待审核事项。 |
| 导出与备份 | 可导出 JSON 草稿、符合审核条件的记录 CSV、可打印 HTML 底稿和复核交接清单。可将数据库、原始 PDF 和页面预览打包备份并恢复到新目录。 |

## 一次典型的使用流程

1. 按客户和税务年度建立工作区，登记应交资料并上传收到的 PDF。
2. 对照原页核对表格类型、本人或配偶归属、付款方及金额，补录遗漏字段并确认页面用途。
3. 查看金额检查和复核交接清单，处理重复记录、缺件和待审核项。
4. 导出录入底稿，在报税软件中完成后续录入和申报流程。

## 当前版本的范围

v0.6 以 2025 税务年度的示例验证为起点，自动识别和金额检查覆盖部分表格、字段和版式。识别结果需要人工确认，导出的已核对记录和交接清单也只反映工作区中已登记的资料与审核进度。税额计算、州税适配、ProSeries 自动录入或导入，以及电子申报均在当前版本范围之外。本机资料、导出和备份由程序以未加密形式保存。

## 快速体验

在 Windows 中双击 `run_windows.bat`，进入界面后点击“载入合成演示资料”，即可用示例走一遍核对流程。安装、OCR 配置和备份恢复步骤见 [README.md](../../README.md)。
